# mvp-figjam-table

> Spreadsheet-style interactive table widget — FigJam-inspired, built with Vue 3 and Vite.

A lightweight embeddable table component that lets users edit cells inline, add/remove rows and columns, and interact with data in a canvas-like experience. Designed for whiteboarding and planning tools.

## Features

- **Inline cell editing** — click any cell to edit, keyboard navigation between cells
- **Dynamic rows/columns** — add and remove rows and columns on the fly
- **FigJam-style UX** — minimal toolbar, drag handles, no modal forms
- **Zero dependencies** — plain Vue 3 Composition API, no external table library

## Tech Stack

| Layer | Technology |
|-------|-----------|
| Framework | Vue 3 |
| Build | Vite |
| Language | JavaScript |

## Getting Started

```bash
npm install
npm run dev    # http://localhost:5173
npm run build  # production bundle
```
